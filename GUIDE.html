상품페이지 템플릿 · 사용 가이드

섹션을 골라 조립하면
HTML 도, Figma 도 함께 나오는 도구

상품페이지는 늘 비슷한 섹션(첫 화면, 고민 공감, 문제 정의, 기능 소개, 가격, FAQ …)으로 만들어요. 이 도구는 섹션마다 Figma 템플릿과 코드 템플릿을 짝지어 두었어요. 그래서 사이트에서 조립한 페이지를 Figma 로 가져가 다듬을 수도 있고, Figma 에서 조립한 페이지를 HTML 로 만들 수도 있어요.

1

고르기

라이브러리에서 섹션·종류를 실제 화면으로 비교

2

조립 · 편집

조합기에서 순서를 정하고, 히어로 편집기에서 첫 화면 문구·배경·버튼 바꾸기

3

Figma 로

「Figma용으로 받기」 → 플러그인으로 원본 컴포넌트 그대로 조립

4

HTML 전달

page.json · Figma 주소로 HTML 을 만들어 개발자에게 전달

누가 무엇을 하나요?

📝 기획자 · 마케터

조합기로 페이지 순서를 잡고, 히어로 편집기에서 첫 화면 시안을 만들어요. 결과는 page.json 또는 Figma 파일로 넘겨요.

🎨 디자이너

받은 파일을 Figma 플러그인으로 조립해 다듬거나, 라이브러리에서 섹션을 골라 Figma 에서 직접 조립해요. 규칙(9번)만 지키면 돼요.

🤖 Claude

Figma 페이지를 읽어 글·이미지를 뽑고 정해진 템플릿으로 HTML 을 조립해요. 새 섹션·모바일 시안도 템플릿에 더해요.

💻 프론트 개발자

만들어진 HTML 을 받아 실제 서비스에 붙여요. 라이브러리 「개발자」 보기에서 코드를 바로 볼 수 있어요.

2사이트 열기 · 화면 구성

설치 없이 브라우저로 열어요: hyjin502.github.io/product-page-templates — 처음에 비밀번호를 물어요(담당자에게 받으세요). 한 번 맞히면 그 브라우저에서는 다시 묻지 않아요.

위쪽 탭라이브러리(섹션 하나씩 보기) · 조합기(페이지 조립) · 히어로 편집기(첫 화면 만들기) · 사용 가이드(이 문서)
기기오른쪽 위 PC 1920 · TB 1024 · MO 375 — 데스크톱·태블릿·모바일 화면을 바로 바꿔 봐요. 모든 탭에 같이 적용돼요.
보기 배율조합기·편집기 미리보기 위 보기: 폭 맞춤 · 25% · 50% · 75% · 100%. 「폭 맞춤」은 창이 좁으면 높이까지 다 보이게 줄여요.
패널 폭왼쪽 패널과 미리보기 사이 경계선을 끌어 폭을 바꿔요(더블클릭하면 원래 폭).
바로가기주소 끝 #compose = 조합기, #hero-editor = 히어로 편집기

새 버전이 안 보이면⌘+Shift+R(Windows Ctrl+F5)로 새로고침하세요.

3라이브러리 — 섹션 보기

왼쪽 목록에서 섹션(hero, concern, problem …)을 누르면 종류(variant)가 펼쳐지고, 오른쪽에 실제 화면이 보여요.

  1. 옵션 바꿔 보기

    섹션 위 칩으로 라이트/다크, 콘텐츠 폭(body 740 · 860 · 980 · 1200 · 가이드), 모바일 전용 배치(compact), 카드 수와 한 줄 최대 개수를 바꿔요. 카드가 많으면 좌우로 넘기는 점(•••)이 생겨요.

  2. 디자이너 / 개발자 보기

    위쪽 보기: 디자이너 · 개발자. 개발자 보기에서는 슬롯 표와 HTML·CSS 코드를 바로 복사할 수 있어요.

  3. Figma 로 이동

    섹션 오른쪽 Figma ▾ → PC 또는 MO 컴포넌트 열기(Dev Mode 링크·링크 복사도 있어요).

  4. 편집기에서 열기

    hero 섹션은 편집기에서 열기를 누르면 바로 히어로 편집기로 넘어가요.

4조합기 — 페이지 조립

"이런 순서면 어떨까?"를 코드 화면으로 빠르게 맞춰 봐요. 왼쪽에서 조립하면 오른쪽 미리보기가 바로 바뀌어요.

  1. 섹션 추가 · 빼기 · 순서

    맨 아래 선택 → 추가, 행 오른쪽 위 ✕ 로 빼기. 순서는 행 위쪽 섹션 이름 줄(⋮⋮)을 잡고 끌어 놓거나 ↑↓ 로 바꿔요.

  2. 종류 고르기

    행 안의 썸네일(3열)을 눌러 그림을 보고 골라요. 누르면 오른쪽 미리보기가 그 섹션으로 이동하고 잠깐 파란 테두리로 알려줘요.

  3. 접기 · 펴기

    목록이 길면 섹션 이름 줄을 누르거나 ▾ 로 행을 접어요. 목록 위 모두 접기 · 모두 펴기.

  4. 카드 수 · 배치

    카드형 섹션은 − 3장 + 로 카드 수를, PC·TB·MO 칸으로 한 줄 최대 개수를 바꿔요. 옵션(compact 등)도 행에서 켜요.

  5. 테마

    미리보기 위 테마: 라이트 · 다크는 페이지 전체, 행마다 있는 테마: 기본 · 라이트 · 다크는 그 섹션만(기본 = 페이지 테마를 따라가요). 히어로는 시안 색 그대로예요.

  6. 히어로 내용

    hero 행의 내용: 샘플 / 히어로 편집기로, 편집기에서 만든 첫 화면을 그대로 넣을 수 있어요. 편집기에서 고치면 조합기에도 바로 반영돼요.

  7. 저장 · 내보내기

    왼쪽 아래 page.json 받기 / 복사(HTML 만들 때), Figma용으로 받기(Figma 로 가져갈 때 — 6번), 기본 순서로(처음 구성으로).

5히어로 편집기 — 첫 화면 만들기

기획자·마케터용 화면이에요. 왼쪽에서 바꾸면 오른쪽 미리보기가 바로 바뀌어요. 입력한 내용은 스타일마다 따로 저장돼요.

  1. 스타일 고르기 (13종)

    썸네일에서 히어로 모양을 골라요 — 배경 위 가운데 문구(media-badge · media-title · light-badge …), 하단 비주얼·제품 화면, 왼쪽 정렬 2단(split-stats · split-photo · media-left · media-left-bottom), 행사용 월간휴넷 LIVE(monthly-live) · 월간X(monthly-x). 스타일마다 바꿀 수 있는 칸이 달라요.

  2. 문구

    칸마다 줄마다 한 칸이고, 글자 수는 줄마다 띄어쓰기 포함으로 세요(오른쪽 9/17). 모바일 문구가 달라야 하면 "MO 문구 따로 쓰기"를 켜요 — PC 칸을 비우고 MO 칸만 쓰면 모바일에만 보여요.

    색 칩으로 타이틀·서브 글자색을 HDS 글자색(검정·흰색 100/80/60/45/비활성) 중에서 바꿔요. 상단 뱃지는 배경색 · 테두리 · 모서리를 고를 수 있어요(「기본」은 시안 그대로).

  3. 배경 · 이미지

    파일 선택(이미지·mp4) 또는 주소 붙여넣기, 파일 없이 CSS 배경(▶ 표시는 천천히 움직여요 — 선셋 빛줄기 · 오로라 · 라이브 글로우 · X 패턴 흐름 등 11종)을 골라요. 모바일 배경을 따로 쓰려면 "MO 도 PC 배경 그대로 쓰기"를 끄고 MO 칸에 넣어요.

    섹션 안 이미지(제품 화면 · 하단 비주얼 · 월간휴넷 비주얼·연사 사진 · 월간X 티켓 사진)는 미리보기에서 그 이미지를 클릭해도 바로 바꿀 수 있어요.

  4. 버튼

    배경색은 HDS 20색(static · interaction · 각 색 700번)과 투명, 라인은 HDS line 4색과 흰색, 모서리는 HDS radius(none 0 ~ full) 중에서 골라요. 글자색은 배경색에 맞춰 자동이에요. 스타일에 따라 모양(채움·테두리)도 바꿔요. 글자 오른쪽 아이콘은 HDS 아이콘 없음(기본) · › chevron-right · → arrow-right · + plus 중에서 골라요(PC·MO 모두 보여요).

  5. 행사형 스타일

    월간휴넷 LIVE: 로고 · 공유 버튼 · 일정 · 진행 방식 · 채널(YouTube 로고) · 연사 사진 최대 3장(오른쪽부터) · MO 신청 버튼. 월간X: 티켓 사진 · 티켓 색(버튼과 같은 HDS 색 — 정보 칸과 사진 위·아래 그라디언트가 함께 바뀌어요) · 티켓 정보 최대 3줄(아이콘 시계·장소·없음) · X 장식.

  6. 기기마다 확인

    PC · TB · MO 로 바꿔 보세요. 줄이 넘치면 미리보기 위 안내줄에 "메인 타이틀 1번째 줄: 2줄로 넘어가요"처럼 나와요.

  7. 보내기

    왼쪽 아래 page.json 받기 / 복사, 조합기에서 보기(조합기 hero 자리에 연결), Figma용으로 받기(이 히어로 하나를 Figma 로 — 6번), 샘플로 되돌리기.

저장입력한 내용·올린 파일은 이 브라우저에 자동 저장돼요. 다른 PC·브라우저·시크릿 창에서는 보이지 않으니 공유할 때는 파일로 받아서 전달하세요. 손대지 않은 샘플 이미지는 샘플이 바뀌면 자동으로 새 샘플을 따라가요.

6Figma 로 가져가기 (플러그인)

조합기나 히어로 편집기에서 만든 결과를 Figma 원본 섹션 컴포넌트 인스턴스로 조립해요. 레이어 · 오토레이아웃이 그대로 살아 있어서 디자이너가 이어서 다듬을 수 있어요.

① 플러그인 설치 — 처음 한 번

  1. Figma 데스크톱 앱 준비

    웹 브라우저 Figma 에서는 개발용 플러그인을 불러올 수 없어요. 데스크톱 앱이 필요해요.

  2. 플러그인 받기

    조합기 왼쪽 아래 Figma 플러그인 받기 (처음 한 번) → zip 을 풀어 폴더를 원하는 곳에 둬요.

  3. 불러오기

    Figma 메뉴 Plugins → Development → Import plugin from manifest… → 풀린 폴더의 manifest.json.

  4. 업데이트

    새 버전은 새 zip 의 파일 3개(manifest.json · code.js · ui.html)를 같은 폴더에 덮어쓰기만 하면 돼요. 다시 Import 하지 않아도 돼요.

② 파일 받기

  1. 페이지 전체

    조합기 → Figma용으로 받기 → 제목.figma.json (아래 자세히)

  2. 히어로 하나만

    히어로 편집기 → Figma용으로 받기 → hero-스타일.figma.json

편집기에서 올린 이미지·영상도 이 파일 안에 함께 담겨요. 샘플 이미지는 플러그인이 저장소에서 직접 받아요(인터넷 연결 필요).

조합기 「Figma용으로 받기」 자세히

조합기에서 만든 페이지 전체를 Figma 로 옮기는 버튼이에요. 순서는 이렇게 해요.

  1. 페이지 제목 정하기

    조합기 맨 위 페이지 제목이 파일 이름(제목.figma.json)과 Figma 프레임 이름(제목 — PC · 제목 — MO)이 돼요. 예: 「AI LABS 상품페이지」.

  2. 섹션 순서·종류 확정

    행 순서가 그대로 Figma 에서 위→아래 순서가 돼요. 종류(썸네일)도 고른 그대로 들어가요. 미리보기에서 한 번 훑어보고 받으세요.

  3. 히어로를 편집기 내용으로

    hero 행의 내용이 「히어로 편집기」면 편집기에서 바꾼 문구·버튼·색·배경이, 「샘플」이면 Figma 시안 그대로 들어가요. 편집기에서 직접 올린 이미지·영상은 파일 안에 함께 담겨요.

  4. 버튼 누르기

    왼쪽 아래 Figma용으로 받기 → 잠깐 뒤 파일이 내려받아져요(올린 영상이 크면 몇 초 걸려요). 이 파일 하나만 디자이너에게 주거나 Figma 플러그인에 넣으면 돼요.

파일에 들어가는 것설명
섹션 목록조합기 행 순서대로 섹션 종류(variant)와 문구·이미지 내용. page.json 과 같은 내용이에요
히어로 편집 내용「히어로 편집기」로 둔 hero 행의 문구(MO 문구 포함) · 글자색 · 뱃지 · 버튼(색·라인·모서리·아이콘) · 배경
올린 파일편집기에서 직접 올린 이미지·영상(파일 안에 함께 담겨요 — 저장소 샘플 이미지는 담지 않고 플러그인이 받아요)
테마페이지·섹션 라이트/다크 — Figma 에서도 섹션 인스턴스의 HDS Theme 변수 모드를 light/dark 로 바꿔 그대로 보여줘요(히어로는 시안 색 그대로). 다크 페이지는 프레임 바탕도 어둡게.
그대로 기록만카드 수·한 줄 개수, 섹션 옵션(compact 등) — 파일에는 들어가지만 Figma 에는 아직 반영하지 않고 「확인할 것」에 알려줘요
page.json 받기와 차이언제 쓰나요
Figma용으로 받기디자이너가 Figma 에서 이어서 다듬을 때. 올린 파일까지 한 파일에 담겨요
page.json 받기HTML 을 만들 때(Claude·개발자·npm run build). 올린 파일은 따로 함께 내려받아져요

섹션마다 결과가 달라요hero 는 문구·버튼·색·배경까지 거의 다 바뀐 채로 들어가요. 나머지 섹션은 원본 컴포넌트가 그대로 들어가고 문구·이미지는 일부만 바뀌어요(Figma 레이어 이름 정리가 끝나면 늘어나요). Figma 에 MO 시안이 없는 섹션(예: split-stats)은 MO 프레임에서 빠지고 「확인할 것」에 적혀요.

다시 받을 때플러그인은 실행할 때마다 새 프레임을 만들어요(이전 결과를 덮어쓰지 않아요). 조합을 고친 뒤 다시 받아 넣고, 필요 없는 예전 프레임은 지워 주세요.

③ Figma 에서 만들기

  1. 원본 파일 열기

    「상품페이지 템플릿 시스템」 파일을 열어요. 다른 파일에서 쓰려면 원본이 팀 라이브러리로 게시돼 있고 그 파일에서 라이브러리를 켜야 해요.

  2. 플러그인 실행

9디자인할 때 지킬 것

이것만 지키면 Figma ↔ HTML 변환이 정확해져요.

  • ① 인스턴스 그대로 쓰기라이브러리 컴포넌트를 복사해서 쓰고, 분리(Detach)하지 않아요.
  • ② 레이어 이름은 표준 이름으로eyebrow · title · description · cta · image 같은 이름이 글자를 찾는 열쇠예요. 문구가 레이어 이름이 되지 않게 해 주세요.
  • ③ 위에서 아래로 쌓기페이지 프레임 바로 안에 섹션을 위→아래 순서로 둬요. 섹션을 그룹으로 묶지 않아요.
  • ④ PC·MO 짝 맞추기새 시안은 섹션 세트 안에 device=pc|mo, layout=… 이름의 컴포넌트로, PC 와 같은 줄에 MO 를 둬요(그래야 다른 파일에서도 플러그인으로 쓸 수 있어요).
  • ⑤ 색·모서리는 HDS 값버튼·뱃지 색과 radius 는 HDS 토큰에서만 골라요. 토큰이 아닌 색은 가장 가까운 토큰으로 바뀌어요.
  • ⑥ 샘플 문구는 실제 문구로컴포넌트 안 글자가 그대로 샘플이 돼요. 날짜·요일 같은 정보는 맞게 넣어 주세요.

10내 PC 에서 직접 빌드하기 (개발자·담당자용 — 사이트만 쓰면 필요 없어요)

컴퓨터마다 처음 한 번만 하면 돼요. 명령어는 복사 버튼을 눌러 붙여넣으세요.

  1. Node.js 설치

    nodejs.org 에서 LTS 를 받아 설치해요. 이미 있으면 건너뛰어요.

  2. 소스 받기

    GitHub 저장소를 받거나(git clone), product-page-templates-src-….zip 을 원하는 곳에 풀어요.

  3. 그 폴더에서 터미널 열기

    Finder 에서 폴더를 오른쪽 클릭 → 서비스 → 폴더에서 새로운 터미널 열기. (없으면 터미널에서 cd 입력 후 폴더를 끌어다 놓고 Enter)

    탐색기에서 폴더를 연 뒤 주소창에 cmd 를 입력하고 Enter.

  4. 준비 (1~2분)
    npm install
  5. 빌드 — 사이트 · 조립 페이지 · Figma 플러그인을 함께 만들어요
    npm run build
  6. 열어 보기
    npm run serve

    브라우저에서 http://localhost:4173 을 열어요.

12막힐 때

화면이 예전 모습이에요

⌘+Shift+R(Windows Ctrl+F5)로 새로고침하세요. 내 PC 에서 빌드했다면 npm run build 를 다시 실행하세요.

편집기 이미지가 깨지거나 예전 이미지가 보여요

예전에 저장된 편집 값 때문일 수 있어요. 새로고침하면 대부분 자동으로 고쳐지고, 그래도 이상하면 왼쪽 아래 샘플로 되돌리기를 눌러 주세요(그 스타일의 입력 내용이 처음으로 돌아가요).

미리보기 아래쪽이 잘려 보여요

창이 좁으면 미리보기 칸이 화면 높이의 60% 예요. 보기 배율을 폭 맞춤으로 두면 전체가 한 번에 보여요.

Figma 플러그인이 「준비 중…」에서 멈춰요

Figma 데스크톱 앱 메뉴(Plugins → Development)에서 열어야 해요. 브라우저에서 ui.html 을 연 것은 동작하지 않아요.

플러그인이 「원본 컴포넌트를 불러오지 못했어요」라고 해요

원본 파일(상품페이지 템플릿 시스템)에서 실행하세요. 다른 파일에서 쓰려면 원본을 팀 라이브러리로 게시하고 그 파일에서 라이브러리를 켜 주세요. 월간휴넷·월간X 는 원본 파일에서만 돼요.

Figma 버튼을 눌렀는데 "권한이 없습니다" 라고 나와요

그 Figma 파일에 초대되지 않은 계정이에요. 파일 담당자에게 보기(또는 편집) 권한을 요청하세요.

HTML 로 바꿨는데 어떤 섹션이 빠졌어요

그 섹션이 분리(Detach)됐거나 아직 코드 템플릿이 없는 섹션일 수 있어요. 인스턴스로 다시 넣거나 Claude 에게 "이 섹션 템플릿에 추가해줘"라고 부탁하세요.

히어로 편집기에 올린 배경이 사라졌어요

올린 파일은 그 브라우저에만 저장돼요. 브라우저 기록을 지웠거나 다른 브라우저·시크릿 창이면 보이지 않아요. 다시 올려 주세요.

줄바꿈이 Figma 와 조금 달라요

웹은 글자 폭이 기기마다 조금씩 달라요. 꼭 바꿀 곳은 편집기에서 줄을 나눠 쓰거나, Figma 에서 직접 줄을 바꿔(Shift+Enter) 두세요.
