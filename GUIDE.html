상품페이지 템플릿 · 사용 가이드

피그마에서 고른 섹션이
그대로 HTML 페이지가 되는 도구

상품페이지는 늘 비슷한 섹션(첫 화면, 고민 공감, 문제 정의, 기능 소개, 가격, FAQ …)으로 만들어요. 이 도구는 그 섹션들을 피그마 템플릿과 코드 템플릿으로 짝지어 두었어요. 그래서 디자이너가 피그마에서 섹션을 골라 조합하면, 똑같은 모양의 HTML 페이지가 만들어져 개발자에게 전달돼요.

💻 프론트 개발자

만들어진 HTML 을 받아 실제 서비스에 붙여요. 코드도 라이브러리에서 바로 볼 수 있어요.

2처음 한 번만 준비하기

컴퓨터마다 처음 한 번만 하면 돼요. 명령어는 복사 버튼을 눌러 그대로 붙여넣기만 하세요.

  1. Node.js 설치

    nodejs.org 에서 LTS(권장) 버튼을 눌러 받은 파일을 설치해요. 다음 → 다음으로 끝까지 누르면 돼요. 이미 있으면 건너뛰어요.

  2. 받은 zip 풀기

    product-page-templates-src-….zip 을 원하는 곳(예: 문서 폴더)에 풀어요.

  3. 그 폴더에서 터미널 열기

    Finder 에서 푼 폴더를 오른쪽 클릭 → 서비스 → 폴더에서 새로운 터미널 열기. (메뉴가 없으면 ⌘+Space → "터미널" 실행 후 cd 를 입력하고 폴더를 창에 끌어다 놓고 Enter)

    탐색기에서 푼 폴더를 연 뒤, 위쪽 주소창을 클릭하고 cmd 라고 입력한 다음 Enter. 검은 창이 열리면 성공이에요.

  4. 준비 명령 실행 (1~2분 걸려요)
    npm install
  5. 사이트 만들기
    npm run build

    ✓ 표시가 나오면 성공이에요. 폴더 안에 dist 가 생겨요.

  6. 라이브러리 열기

    dist 폴더의 index.html 을 더블클릭하면 브라우저에서 열려요. 즐겨찾기에 추가해 두세요.

팁파일을 고친 뒤 화면이 그대로면 npm run build 를 한 번 더 실행하고 브라우저를 새로고침하세요.

3라이브러리에서 섹션 가져다 쓰기

왼쪽 목록에서 섹션(hero, concern, problem …)을 누르면 종류가 펼쳐지고, 오른쪽에 실제 화면이 보여요.

  1. 기기 바꿔 보기

    오른쪽 위 PC 1920 · TB 1024 · MO 375 를 누르면 데스크톱·태블릿·모바일에서 어떻게 보이는지 바로 확인돼요.

  2. 옵션 바꿔 보기

    각 섹션 위의 칩으로 라이트/다크, 콘텐츠 폭(body), 모바일 전용 배치(compact), 카드 수와 한 줄 최대 개수를 바꿔 볼 수 있어요. 카드가 적으면 넓어지고, 많으면 좌우로 넘기는 점(•••)이 생겨요.

  3. 피그마로 이동

    섹션 오른쪽 Figma ▾ 버튼 → PC 또는 MO 컴포넌트 열기. 피그마에서 그 섹션이 바로 열려요.

  4. 내 페이지에 복사

    피그마에서 컴포넌트를 인스턴스로 복사(⌥+드래그 또는 ⌘C→⌘V)해서 내 페이지 프레임에 붙이고, 글과 이미지만 바꿔요.

주의인스턴스를 분리(Detach)하거나 레이어 이름을 바꾸면 나중에 HTML 로 바꿀 수 없어요.

4조합기로 페이지 미리 보기

피그마 작업 전에 "이런 순서면 어떨까?"를 코드 화면으로 빠르게 볼 수 있어요. 상단 조합기 를 누르세요.

  1. 섹션 순서 정하기

    왼쪽에서 섹션을 추가(아래 선택 → 추가)·삭제(✕)·이동(↑↓)하고, 종류(variant)를 골라요.

  2. 카드 수·배치 조절

    카드형 섹션은 − 3장 + 로 카드 수를, PC·TB·MO 칸으로 한 줄 최대 개수를 바꿔요.

  3. 저장

    왼쪽 아래 page.json 받기 를 누르면 지금 구성이 파일로 저장돼요. 이 파일을 Claude 나 개발자에게 주면 같은 구성으로 HTML 을 만들 수 있어요.

5히어로 편집기 — 첫 화면 시안 직접 만들기

기획자·마케터용 화면이에요. 상단 히어로 편집기 를 누르거나 주소 끝에 #hero-editor 를 붙여 열어요. 왼쪽에서 바꾸면 오른쪽 화면이 바로 바뀌어요.

  1. 스타일 고르기

    맨 위 썸네일 7개 중에서 히어로 모양을 골라요. 스타일마다 바꿀 수 있는 항목이 달라요 (예: 배경 어둡게, 하단 비주얼, 제품 화면). 스타일마다 입력한 내용이 따로 저장돼요.

  2. 문구 넣기

    뱃지·타이틀·서브타이틀을 칸마다 입력해요. 타이틀은 줄마다 한 칸이고 최대 2줄, 줄마다 17자(띄어쓰기 포함)예요. 서브타이틀은 1~2줄, 줄마다 20자예요. 오른쪽 숫자(예: 9/17)로 남은 글자를 확인해요. 뱃지는 글자 길이만큼 늘어나요.

  3. 배경 바꾸기

    파일 선택으로 이미지나 mp4 영상을 올리거나 주소를 붙여 넣어요. 모바일 배경을 따로 쓰려면 "MO 도 PC 배경 그대로 쓰기" 체크를 끄고 MO 칸에 넣어요.

  4. 버튼 꾸미기

    버튼은 최대 2개예요. 배경색은 디자인 시스템(HDS) 색 중에서, 모서리 둥글기도 HDS 값(xs 4 ~ full) 중에서 골라요. 글자색은 배경색에 맞춰 자동으로 정해져요. 스타일에 따라 모양(채움·테두리)과 화살표도 바꿀 수 있어요.

  5. 기기마다 확인

    오른쪽 위 PC · TB · MO 로 바꿔 보세요. 미리보기 위 안내줄에 "메인 타이틀 1번째 줄: 2줄로 넘어가요" 처럼 줄이 넘치는 곳이 나오면 문구를 줄이거나 줄을 나눠요.

  6. 전달하기

    왼쪽 아래 page.json 받기 를 누르면 page.json 과 올린 배경 파일이 함께 내려받아져요. 이 파일들을 디자이너·개발자에게 주면 같은 화면의 HTML 이 만들어져요.

모바일지금 모바일(MO) 화면은 임시 배치예요. 히어로별 모바일 디자인이 나오면 그대로 바뀌어요.

저장입력한 내용은 이 브라우저에 자동 저장돼요. 다른 PC·다른 브라우저에서는 보이지 않으니, 공유할 때는 page.json 을 받아서 전달하세요. 처음 상태로 돌리려면 샘플로 되돌리기.

7팀·개발자에게 전달하기

하고 싶은 것방법
완성 페이지 전달dist/pages/페이지이름/ 폴더를 통째로 압축해서 프론트 개발자에게 전달해요. 안에 index.html 과 이미지가 다 들어 있어요.
라이브러리를 팀에 공유아래 명령으로 release 폴더에 site zip 이 생겨요. 사내 웹서버 담당자에게 "이 zip 을 풀어서 올려 주세요"라고 전달하면 돼요.
npm run pack
히어로 시안 전달히어로 편집기의 page.json 받기 로 받은 page.json 과 배경 파일을 함께 전달해요. 받은 사람은 두 파일을 pages/ 폴더에 넣고 npm run build 하면 dist/pages/ 에 HTML 이 생겨요.
다른 PC·동료에게 도구 자체 전달같은 npm run pack 으로 생긴 src zip 을 주면 돼요. 받는 사람은 2번(처음 한 번만 준비하기)부터 하면 돼요.

8디자인할 때 지킬 것

이 네 가지만 지키면 피그마 → HTML 변환이 정확해져요.

  • ① 인스턴스 그대로 쓰기라이브러리 컴포넌트를 복사해서 쓰고, 분리(Detach)하지 않아요.
  • ② 레이어 이름 바꾸지 않기eyebrow · title · description · cta · image 같은 이름이 글자를 찾는 열쇠예요.
  • ③ 위에서 아래로 쌓기페이지 프레임 바로 안에 섹션을 위→아래 순서로 둬요. 섹션을 그룹으로 묶지 않아요.
  • ④ PC·MO 순서 맞추기모바일 프레임도 같은 섹션을 같은 순서로 두면 줄바꿈까지 알아서 맞춰져요.

9용어 풀이

섹션페이지를 이루는 큰 덩어리. 예) hero(첫 화면), concern(고민 공감), faq(자주 묻는 질문)
variant같은 섹션의 다른 모양. 예) feature 의 grid-default · grid-card · grid-media
옵션같은 variant 안에서 켜고 끄는 변형. 예) 모바일에서 좌우로 넘기는 compact, 다크 모드
PC · TB · MO데스크톱(1280px 이상) · 태블릿(768–1279px) · 모바일(767px 이하) 화면
page.json"어떤 섹션을 어떤 순서로, 어떤 글로" 쓸지 적어 둔 설명서 파일. 이걸로 HTML 을 만들어요
빌드(build)템플릿과 page.json 을 합쳐 실제 화면(HTML)을 만드는 일. npm run build
라이브러리 / 조합기섹션을 하나씩 보는 화면 / 섹션을 이어 붙여 페이지로 보는 화면
히어로 편집기첫 화면(hero)의 문구·배경·버튼을 직접 바꿔 보는 화면
HDS휴넷 디자인 시스템. 편집기의 버튼 색·모서리 값은 여기서만 골라요

10막힐 때

"npm 을 찾을 수 없습니다" 라고 나와요

Node.js 가 설치되지 않았어요. 2번의 ① 을 다시 하고, 터미널을 닫았다가 새로 열어 주세요.

index.html 을 열었는데 화면이 비어 있거나 예전 모습이에요

터미널에서 npm run build 를 다시 실행하고 브라우저를 새로고침(⌘+R / F5)하세요.

Figma 버튼을 눌렀는데 "권한이 없습니다" 라고 나와요

그 피그마 파일에 초대되지 않은 계정이에요. 파일 담당자에게 보기(또는 편집) 권한을 요청하세요.

Claude 가 피그마를 못 읽는대요

Claude Code 에서 /mcp 로 Figma 연결 상태를 확인하고, 끊겨 있으면 다시 연결(로그인)해 주세요. 피그마 파일 열람 권한도 필요해요.

HTML 로 바꿨는데 어떤 섹션이 빠졌어요

그 섹션이 분리(Detach)됐거나, 아직 코드 템플릿이 없는 섹션일 수 있어요. Claude 가 결과와 함께 "변환하지 못한 섹션" 목록을 알려줘요. 인스턴스로 다시 넣거나 "이 섹션 템플릿에 추가해줘"라고 부탁하세요.

히어로 편집기에 올린 배경이 사라졌어요

올린 파일은 그 브라우저에만 저장돼요. 브라우저 기록을 지웠거나 다른 브라우저·시크릿 창이면 보이지 않아요. 배경 칸에서 파일 선택으로 다시 올려 주세요.

줄바꿈이 피그마와 조금 달라요

웹은 글자 폭이 기기마다 조금씩 달라서 자동 줄바꿈 위치가 바뀔 수 있어요. 꼭 바꿀 곳은 피그마에서 직접 줄을 바꿔(Shift+Enter) 두면 그대로 옮겨져요.
